# DIY 聖誕樹 教學簡報(網頁版)

純靜態網頁,打開 `index.html` 即可播放(離線也可以)。

## 放到 GitHub Pages
1. 在 GitHub 建立新的 repository(例如 `xmas-tree`)。
2. 把這個資料夾裡的 `index.html` 和 `assets/` 整個上傳到 repository 根目錄。
3. Settings → Pages → Source 選 `Deploy from a branch`,Branch 選 `main`、資料夾 `/ (root)` → Save。
4. 約 1 分鐘後網址是 `https://<你的帳號>.github.io/<repository 名稱>/`。

## 操作
- 下一頁:→ / 空白鍵 / 點畫面 / 手機左滑
- 上一頁:← / 點畫面最左邊 / 手機右滑
- F:全螢幕 N:顯示講稿 Home/End:第一頁/最後一頁
- 網址後加 `#8` 可以直接開到第 8 頁
